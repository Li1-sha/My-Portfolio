University Library Management System

Full-stack web app for book cataloging, member management, and automated fine handling.

Problem: Manual library records at Omani universities were error‑prone, lacked real‑time stock visibility, and fine calculations were inconsistent.

Solution: Built a full‑stack system with Node.js + Express (backend), React + Vite (frontend), and SQLite with Sequelize ORM. Features automated 1 OMR/day late fine calculation, copy availability checks, and a real‑time dashboard tracking books, members, active borrows, overdue items, and total unpaid fines.

Impact: Eliminated manual tracking errors, automated fine calculations, enabled one‑click fine payments, and included a one‑click demo data seeder for instant testing. Built with a clean, responsive UI using Inter font.
